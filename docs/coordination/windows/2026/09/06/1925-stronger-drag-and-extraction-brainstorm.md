# 減速比較版0.6.1と「破壊・回収・持ち帰り」構想メモ

## 今回の目的

実装するのは現在のChallengeの減速強化だけ。別ゲームの一要素として転用する360度採掘・回収・帰還の発想は，以下へ未採用メモとして保存する。旧試作・Build・Saveは削除しない。

## 会話からの開発記録

### Userの指示・観察

- 現状は，どこへ狙っても分裂・反射で盤面全体へ広がり，狙う意味が薄い。終盤ならこの暴れ方でもよいが，序盤を少し抜けた段階としては強すぎるのではないか。
- 最初の「減少量を減らす」は速度についての表現だったが，最終的に「減少量を増やす，マイナスの値を大きくする」と明確に訂正。意図は減速を強めることで確定。
- 命中時を中心に時間減速も強め，初速・分裂・弾数・止まり際を同時に変えない比較作業を承認。

### Userの新構想（9項目を要約，いずれもメモ案）

1. 今回の試作を，別のゲームを構成するミニゲームの一つにする可能性。
2. 四角い盤面ではなく，周囲360度へ広がる平面へ変更。バンパーや拡張性の役割は変わるが許容範囲。
3. 実際に見る範囲は90度以下。Mouse移動，またはButtonで視野方向を変える。360度全体を同時に見る画面ではない。
4. Cookie Clickerのクリック操作を射撃に置換するイメージ。射撃でGold／素材を得て，自動追撃，弾強化，武器種，自動生産を開放する。
5. 防衛ゲームにはしたくない。放置寄りにする可能性。ホーミング／レーザーなども候補。
6. 「撃つ→壊す→手に入れる」が中心。破壊で細かくし，破片を網など別の手段で回収。資源を回収装置・回収間隔・武器・自動生産力の強化へ使う。
7. 一か所の拠点から移動し，破壊・採集して戻る構造も考えた。移動自体がエネルギーを使い，速度やエネルギー容量を強化する。ただし当初Conceptからずれる懸念。
8. 宇宙／Crystalの美術なら，HPに応じた大きさや色で鉱石の違いを表現できる。採掘して持ち帰る遊びとTarkov的な脱出要素の相性を感じる。
9. 素材のカバン内テトリス，持ち帰れなければ0／半減などのリスク。狙いそのものを副目的とし，主目的を「壊して得たものを持ち帰る」に移してはどうか。ただしインクリメンタルではなくなるのでは，という疑問。

上記は元の番号を機械的に転記したものではなく，冒頭のミニゲーム案も含めて意味ごとに再整理した要約。Userの疑問・選択肢を確定仕様に読み替えない。

### Assistantの整理・提案（新構想は未実装）

**「持ち帰り型・採掘インクリメンタル」なら両立可能と考える。** インクリメンタルを成立させる軸を，戦闘中の弾数ではなく，持ち帰った資源で永続的に増える採掘力・回収力・生産力へ置く。これは設計提案であり，既存Masterの製品定義を変更したものではない。

- 基本Loop案：拠点で準備→採掘場へ出る→鉱石を破壊→破片を回収→帰還して素材確定→武器／回収／自動生産を恒久強化。現在の射撃場は「能動的な産出ミニゲーム」として内包できる。
- 射撃の選択は，細かい反射最適化だけでなく「どの鉱石を優先するか」「粉砕するか大きな塊で回収するか」「残容量で何を積むか」へ広げられる。ただし射撃自体が退屈なままでよいわけではなく，今回の減速比較は独立して価値がある。
- リスクはまず未帰還の今回の積荷に限定し，解放済み武器・恒久設備・既に持ち帰った素材を失わない案。0／半減の選択は未確定。全損は緊張を生む一方，気軽な放置志向と衝突するので，最初から必須にしない。
- 防衛を主軸にせず，容量・燃料・遠い資源の価値で「もう少し掘る／戻る」を選ぶ設計は可能。帰還分のエネルギー目安を明示し，危険を知らずに足止めされる状態を避けたい。敵による攻撃・拠点HP・防衛Waveは今回の案から必然には導かれない。
- 放置生産と能動採掘の住み分け案：自動生産で基礎資源を得て，手動採掘で設備解放素材や高効率の産出を得る。手動だけを延々必須にする／自動が全て代替して射撃の意味をなくす，の両極を避けたい。数値・希少素材体系は未定。
- 「拠点固定で砲台旋回」と「船を操縦して移動・帰還」は別の試作規模。まず帰還Loopを狭い採掘エリアで試し，移動を追加する価値が確認できたらエネルギー・速度を足す順を提案。360度化だけを先に行っても採集・帰還の面白さは検証できない。
- 90度視野は未知の領域へ向く楽しさを作れるが，見えない背後で取り返しのつかない損失が起きる設計は避けたい。拠点方向・回収物の残量・帰還可能範囲を読める補助表示を候補とする。
- 荷物テトリスは「何を持ち帰るか」の選択と相性があるが，毎回の細かい並べ直しは放置志向と衝突。まず容量だけで試し，手動整理の利点／自動整理の解放を後で比較する案。
- 破片を増やすと描画・回収処理も増える。演出の破片全てを独立した価値持ちItemにする必要はない。鉱石を割るたび無条件に素材総量が増殖しないよう，素材価値の保存と明示的な収率強化を分ける案。
- 仮の次順序：現行減速版を試遊→別試作で破壊・回収・帰還・強化を1周だけ作る→移動と360度／狭視野を比較→荷物整理・自動生産・多種武器を必要な順に追加。Userから次の実装承認が出るまでは進めない。
