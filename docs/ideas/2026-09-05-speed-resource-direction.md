# 採用する試作方針：速度資源型マガジン・ピンボール

Userが2026年9月5日に「その方針でメモ」「その方針でプロトタイプを更新」と承認した．正本化した範囲はMaster §32とMomentum Briefを参照する．この文書は判断の記録である．

## 期待していた遊び

- 五発を一発ずつクリックする循環Recipeではなく，一クリックで仕込んだマガジンを撃ち切る．
- 銃の装弾数・発射間隔・弾の性質で盤面への働きかけが変わる．ピストル1→7発，M4の30発などは将来案であり，今回の実装数値ではない．
- 一度解いた経路を繰り返す固定配置より，ランダムな的・障害物と動く効果ゾーンへ狙って撃ち込む方向．
- 銃から弾を撃ち出すピンボールの感覚．壁反射は倍率取得ではなく，弾を盤面へ戻す物理的な役割．

## 今回の核

- 速度＝弾が働き続けられる勢い．時間経過と的への接触で失う．尽きたら消滅し，残れば的を通過．
- 命中ダメージ＝基礎威力×基準速度に対する速度倍率．上限あり．命中直前の速度でダメージ計算後，抵抗による減速を処理する．
- アーマーは抵抗値．通常弾もダメージを与えられ，速度が足りれば抜けられる．特定弾以外無効の鍵穴にはしない．
- 通常弾は基礎威力が高い．貫通弾は抵抗係数が低く，奥まで届く．
- 加速ゾーンは弾速×2，上限あり，同じ弾が同じゾーンで強化されるのは一回．
- 板の自由配置，旧Primer，Capacity，五発循環は別の旧試作として保存．

## 保存する将来候補

- ゴールド弾化／報酬2倍ゾーン，貫通力強化ゾーン，強化とランダム方向変更を組み合わせるカオスゾーン．
- 銃種・弾倉成長・弾サイズ，裂傷／破砕系，爆発による範囲攻撃・装甲無視．
- 速度が十分に高い場合の非線形抵抗．現実の弾道を再現する技術仕様としては扱わない．
- 全弾終了待ちは停滞の可能性があるため，今回は撃ち切り後Reloadを採用．
